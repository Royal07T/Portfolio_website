# Royalty Portfolio

This repository is now a **plain static portfolio website** built with:

- `HTML`
- `CSS`
- `JavaScript`

The site has been restructured so the static frontend lives directly at the repository root for easier deployment on platforms like GitHub Pages, Netlify, Vercel static hosting, or any basic web server.

## Project structure

- `index.html` — main portfolio page
- `assets/css/styles.css` — custom styling
- `assets/js/main.js` — site data and interactions
- `assets/images/` — portfolio images
- `favicon.ico` — site favicon
- `robots.txt` — crawler rules

## Features

- Responsive custom layout
- Mobile navigation menu
- Scroll reveal animations
- Dynamic skills, projects, and experience sections rendered with vanilla JavaScript
- Contact form validation with `mailto:` handoff to the user’s default email app

## How to run

### Option 1: Open directly

Open `index.html` in your browser.

### Option 2: Serve locally

From the repository root, run:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000/
```
